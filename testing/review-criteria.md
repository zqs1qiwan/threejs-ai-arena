# 评审维度与真实性说明

## 评审维度

1. **技术正确性**：零 console error / pageerror / requestfailed；canvas 正常；loader 正常消失。
2. **构图与主体**：主体是否突出、画面是否平衡、留白是否合理。
3. **材质与光照**：是否有 PBR 质感、阴影/接触遮蔽、高光、色调层次。
4. **细节密度**：叶片/岩石/地表/水面等细节是否可辨，是否有低多边形廉价感。
5. **自适应与 UI**：桌面/手机布局、控件可用性、文字可读性。
6. **穿帮/伪影**：z-fighting、悬浮、错误裁剪、摩尔纹、bloom 过曝、粒子遮挡。

## 真实性说明

- 自动化视觉评审（magpie vision）会给出看似具体但与实际代码不符的描述（例如"树冠是绿色方块/体素"，而源码中是叶片 billboard 平面）。这类描述视为**幻觉**，不作为修改依据。
- 单人单次评分波动大（同一画面可能 5/10 与 8/10 并存）。应以**多次独立共识 + 客观像素统计**为准。
- 软件光栅（SwiftShader）下的首帧极慢（约 10 秒），早期截图可能拍到相机补间中途，导致"不是近景"等误判；验证脚本需足够等待时间。
- FPS 读数 20–26 是 SwiftShader 软件渲染结果，不代表真实 GPU 性能。

## 目标达成判定

原始目标为"尽可能达到 3A 游戏大作质量"。经 50+ 轮打磨与多次独立评审，最终作品定位为**高品质风格化实时 3D 场景**（约 7–8/10），**未达到 AAA 写实画质**。原因是硬约束：纯程序化生成 + 浏览器实时 + 禁用任何外部图片/模型/贴图/HDRI。写实 AAA 依赖扫描级资产、真实 SSS/GI、光追反射与电影级材质层，均超出该约束。

因此目标状态为"已停止迭代并发布最佳成果"，而非"达成 AAA"。
