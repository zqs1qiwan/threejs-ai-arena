# 验证逻辑与结果记录

## 验证方法

本项目采用"实现 → 截图 → 视觉评审 → 改最弱项 → 再评测"闭环。验证分三层：

### 1. 自动化技术验证（`verify.mjs`）

- 用 puppeteer + Chrome（headless，SwiftShader 软件光栅）打开指定 URL
- 捕获 `console`（warning/error）、`pageerror`、`requestfailed`
- 等待首帧稳定（软件渲染首帧较慢，`fps` 从 0 跳到 20+ 属正常）
- 输出 canvas 尺寸、loader 状态、季节标签、FPS
- 截图供视觉评审

判定标准：**ISSUES none**（零控制台报错 / 零页面异常 / 零失败请求）。

### 2. 自动化视觉评审（`vision.ps1`）

- 将截图以 base64 data-url 交给 magpie vision MCP（`magpie-vision__analyze_image`）
- 使用中性提示词（避免诱导性描述），多次独立读取取共识
- 关注：构图、 foliage 细节、光照/阴影、水面、山体、UI 可读性、穿帮/伪影

> 注意：自动视觉评审存在提示漂移与偶发幻觉（例如把 billboard 叶片描述为"voxel blocks"）。判断质量时以**多次共识 + 客观像素统计**为准，单次描述的细节不可全信。

### 3. 客观像素统计

用 Python/PIL 计算亮度均值、标准差、边缘能量、高光裁剪比例等，辅助判断"过曝/对比度/锯齿"等主观描述是否成立。

## 历轮打磨要点（摘要）

- 渲染管线：PMREM 程序化 IBL、GTAO、Bokeh DOF、Bloom、SMAA/MSAA/alpha-to-coverage 后处理
- 季节系统：四季配色与粒子（花/萤火/落叶/雪）、昼夜四时段（太阳角度、天空色、IBL、灯笼光）
- 几何细节：完整五裂枫叶贴图 + billboard 树冠、纺锤形锦鲤、多层石灯笼、鸟居、接地竹林、柔化石块
- 材质/地表：程序化树皮/岩石/沙地法线、沙纹浮雕、地面斑驳、水面焦散与高光
- UI：季节条、速度/播放/环绕/画质/近景/时段/重置、快捷键、loader、WebGL2 降级提示

多轮尝试但因验证不佳回退的方向：平面/立方体反射、几何沙地浮雕、默认档真实阴影、AgX 色调映射、睡莲花、拱桥、叶片 UV 重裁。
