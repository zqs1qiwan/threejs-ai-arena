# 四季園 · SHIKI-EN

程序化生成的实时 3D 四季禅意盆景场景（Vite + Three.js + TypeScript，100% 纯代码生成，零外部图片/模型/贴图/HDRI）。

- **模型**：Gemini 4 Hydrogen (Medium)
- **题材**：四季盆景微缩山水（春樱吹雪 · 夏翠萤火 · 秋枫映水 · 冬雪禅灯）

## 归档内容

| 路径 | 内容 |
|------|------|
| `dist/` | 最终静态构建产物（`dist/index.html` 与 `dist/assets/`） |
| `src/` | 完整 TypeScript / GLSL 着色器源码 |
| `index.html` | 入口页面源码 |
| `package.json` / `vite.config.ts` / `tsconfig.json` | Vite 与 TypeScript 构建配置 |

## 核心特性

- **全程序化 PBR 材质与着色器**：FBM 噪声实时生成树皮法线/粗糙度、釉面陶瓷、紫檀木纹、赏石纹理、苔藓法线、大气天空穹顶、世界空间法线积雪着色器、水波与冰封着色器。
- **动态四季与交互**：支持四季连续平滑演化与时间轴拖拽、5 组预设视角、清昼/暮金/月夜光影切换、风力调节、点击树冠吹起落英、点击石灯笼开关灯火、点击池水泛起涟漪，桌面与移动端自适应。
